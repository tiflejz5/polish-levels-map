# Genitive: negation, possession and common prepositions

English says "I have **time**" and "I don't have **time**" with the same word. In Polish the object changes when you add *nie*: *Mam czas. → Nie mam czasu.* This form is the **genitive** (*dopełniacz*, questions: *kogo? czego?*). It also does the job of English "of" and "'s" (*dom brata*, "my brother's house"), and it follows five very common prepositions: *do, z* (from), *od, bez, dla*.

## How it works

Singular. The plural comes at A2.

| Gender | Noun | Adjective | Nominative → genitive |
| --- | --- | --- | --- |
| masculine | **-a** or **-u** | **-ego** | *dobry brat → dobrego brata*, *czas → czasu* |
| feminine | **-y** (after *k, g, l, j* and in *-ia*: **-i**) | **-ej** | *zimna kawa → zimnej kawy*, *książka → książki* |
| neuter | **-a** | **-ego** | *zimne piwo → zimnego piwa* |

Masculine: people and animals almost always take **-a** (*brata, psa, kota*; for *tata, kolega* see below). Things take *-a* or *-u*, so learn the genitive with the word:

| **-a** | **-u** |
| --- | --- |
| *chleb → chleba* | *czas → czasu* |
| *ser → sera* | *dom → domu* |
| *Kraków → Krakowa* | *sklep → sklepu* |
| *Gdańsk → Gdańska* | *samochód → samochodu* |

Feminine *-i*: *Polska → Polski*, *Ola → Oli*, *kuchnia → kuchni*.

## When to use it

1. **The object after *nie*:** *Nie mam brata.* (I don't have a brother.) *Nie lubię kawy.* (I don't like coffee.)
2. ***nie ma* = "there isn't" or "is not here":** *Nie ma mleka.* (There's no milk.) *Ani nie ma.* (Ania isn't here.)
3. **"of" and "'s":** the owner comes **after** the thing: *dom brata* (my brother's house), *imię psa* (the dog's name).
4. **After *do* (to), *z* (from), *od* (from a person, since), *bez* (without), *dla* (for):** *Jadę do Krakowa.* *Jestem z Polski.* *To list od mamy.* *Kawa bez cukru.* *To dla Oli.*

Only the object of *nie* changes. A noun after *nie jest* stays as it was: *To nie jest mój telefon.* *Kuba nie jest lekarzem.*

## Examples

| Polish | English |
| --- | --- |
| Przepraszam, nie mam czasu. | Sorry, I don't have time. |
| W domu nie ma chleba. | There's no bread at home. |
| To jest samochód taty. | This is Dad's car. |
| Idę do sklepu. | I'm going to the shop. |
| Paweł jest z Wrocławia. | Paweł is from Wrocław. |
| Mam prezent od siostry. | I've got a present from my sister. |
| Herbata bez cukru, proszę. | Tea without sugar, please. |
| Ta kawa jest dla pani Ewy. | This coffee is for Mrs Ewa. |

## Good to know

- *z* + genitive is "from": *z Polski*. *z* + instrumental is "with": *z mlekiem*. Same word, different ending: [[a1-cases-instrumental-identity]].
- Watch the mobile *e*: *cukier → cukru*, *pies → psa*, *ojciec → ojca*.
- Men's words in *-a* take *-y* like feminine nouns: *kolega → kolegi*, *tata → taty*.
- *u* + genitive means "at someone's place": *u babci* (at Grandma's).
- *dużo* (a lot of) and *mało* (little) take the genitive too: *dużo czasu*.

## Common mistakes for English speakers

- ✗ *Nie mam czas.* → ✓ *Nie mam czasu.* — after *nie* the object takes the genitive.
- ✗ *Nie lubię kawę.* → ✓ *Nie lubię kawy.* — the accusative *kawę* becomes the genitive *kawy* after *nie*.
- ✗ *Nie ma mleko.* → ✓ *Nie ma mleka.* — *nie ma* ("there isn't") always takes the genitive.
- ✗ *brata dom* → ✓ *dom brata* — the owner comes after the thing, not before it as in English.
- ✗ *kawa bez cukier* → ✓ *kawa bez cukru* — *bez* takes the genitive.

## Practice

Put the word in brackets into the genitive.

1. Nie mam (czas) ___.
2. Nie ma (woda) ___.
3. Jadę do (Gdańsk) ___. (-a)
4. Kawa bez (mleko) ___.
5. To jest pokój (siostra) ___.
6. Prezent dla (mama) ___.

Correct the mistake.

7. Nie lubię herbatę.

Translate into Polish.

8. I don't have a car.

## Answers

1. czasu
2. wody
3. Gdańska
4. mleka
5. siostry
6. mamy
7. Nie lubię herbaty.
8. Nie mam samochodu.
