# Questions and negation

English needs a helper verb for questions and negatives: "**Do** you work?", "I **don't** work". Polish has no helper. A question is the normal sentence with *czy* in front (or just a rising voice): *Czy pracujesz?* A negative is *nie* in front of the verb: *Nie pracuję.* One more difference: words like "nobody", "nothing" and "never" still need *nie* with the verb, so Polish says "nobody **not** knows": *Nikt nie wie.*

## How it works

Yes / no questions:

| Statement | Question | Answer |
| --- | --- | --- |
| *Mówisz po polsku.* | ***Czy*** *mówisz po polsku?* | *Tak, mówię.* / *Nie, nie mówię.* |
| *Pan jest z Polski.* | ***Czy*** *pan jest z Polski?* | *Tak.* / *Nie, jestem z Irlandii.* |

Question words:

| Polish | English | Example |
| --- | --- | --- |
| *co* | what | *Co robisz?* |
| *kto* | who | *Kto to jest?* |
| *gdzie* | where | *Gdzie mieszkasz?* |
| *skąd* | where from | *Skąd jesteś?* |
| *kiedy* | when | *Kiedy masz czas?* |
| *jak* | how | *Jak się masz?* |
| *ile* | how much, how many | *Ile to kosztuje?* |
| *dlaczego* | why | *Dlaczego nie jesz? — Bo nie jestem głodny.* |
| *jaki, jaka, jakie* | what … like, what kind of | *Jaka jest twoja szkoła?* |

The question word comes **first**; the rest keeps normal order: *Gdzie pracuje Ola?* or *Gdzie Ola pracuje?* *Jaki* agrees with its noun: *jaki dom, jaka kawa*.

Negation:

| Positive | Negative |
| --- | --- |
| *Rozumiem.* | ***Nie*** *rozumiem.* |
| *To jest mój telefon.* | *To* ***nie*** *jest mój telefon.* |
| *Ktoś wie.* (Somebody knows.) | ***Nikt nie*** *wie.* (Nobody knows.) |
| *Rozumiem wszystko.* (I understand everything.) | ***Nic nie*** *rozumiem.* (I don't understand anything.) |
| *Pracuję w niedzielę.* | ***Nigdy nie*** *pracuję w niedzielę.* (I never work on Sundays.) |

## When to use it

1. **Yes / no questions with *czy*:** *Czy masz czas?* (Have you got time?)
2. **Yes / no questions without *czy*:** in speech, just raise your voice: *Masz czas?*
3. **Questions with a question word**, which comes first: *Gdzie pracuje Ola?* (Where does Ola work?) Do not add *czy*.
4. **Saying no:** *nie* goes directly before the verb: *Nie mieszkam tu.* (I don't live here.) Answering "no" often gives two *nie*: *Nie, nie mieszkam.*
5. **"Nobody, nothing, never":** *nikt, nic, nigdy* + *nie* + verb: *Nigdy nie mam czasu.* (I never have time.)

## Examples

| Polish | English |
| --- | --- |
| Czy pani mówi po angielsku? | Do you speak English? (to a woman) |
| Gdzie jest dworzec? | Where is the station? |
| Kiedy jedziesz do Gdańska? — W piątek. | When are you going to Gdańsk? — On Friday. |
| Dlaczego Marta nie je? — Bo jest zmęczona. | Why isn't Marta eating? — Because she's tired. |
| Przepraszam, nie rozumiem. | Sorry, I don't understand. |
| Kuba nie jest lekarzem, jest nauczycielem. | Kuba isn't a doctor, he's a teacher. |
| Nikt nie wie, gdzie jest klucz. | Nobody knows where the key is. |
| Jak masz na imię? — Paweł. | What's your name? — Paweł. |

## Good to know

- *Kto* and *co* take the "he / she" form of the verb: *Kto ma czas?* (Who has time?) *Co jest w lodówce?* (What's in the fridge?)
- *Dlaczego?* is answered with *bo* (because).
- After *nie* an object changes its ending (*Mam czas. → Nie mam czasu.*): see [[a1-cases-genitive-basics]].

## Common mistakes for English speakers

- ✗ *Rozumiem nie.* → ✓ *Nie rozumiem.* — *nie* goes before the verb, not after it.
- ✗ *Nie, rozumiem.* (for "No, I don't understand") → ✓ *Nie, nie rozumiem.* — the first *nie* is "no", the second makes the verb negative.
- ✗ *Nikt wie.* → ✓ *Nikt nie wie.* — *nikt, nic, nigdy* need *nie* with the verb.
- ✗ *Gdzie jesteś z?* → ✓ *Skąd jesteś?* — "where … from" is one word: *skąd*.
- ✗ *Co jest twoje imię?* → ✓ *Jak masz na imię?* — Polish asks "how" about your name.

## Practice

Make the sentence negative.

1. Rozumiem.
2. Pracuję w sobotę.
3. To jest moja kawa.

Choose the question word: *gdzie, kiedy, skąd, dlaczego*.

4. ___ mieszkasz? — W Poznaniu.
5. ___ jesteś? — Z Kanady.
6. ___ masz czas? — Jutro.

Correct the mistake.

7. Nikt wie.

Translate into Polish.

8. Do you speak Polish? (to a friend)

## Answers

1. Nie rozumiem.
2. Nie pracuję w sobotę.
3. To nie jest moja kawa.
4. Gdzie
5. Skąd
6. Kiedy
7. Nikt nie wie.
8. Czy mówisz po polsku? / Mówisz po polsku?
