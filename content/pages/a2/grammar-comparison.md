# Comparing: adjectives and adverbs

English adds "-er" and "-est" or uses "more" and "most". Polish works the same way: an ending **-szy / -ejszy** for "-er", the prefix **naj-** for "-est", and *bardziej* (more) for long words. The comparative is an adjective, so it agrees with the noun: *tańszy bilet, tańsza kawa, tańsze mieszkanie*. "Than" is *niż*: *Kraków jest mniejszy niż Warszawa.*

## How it works

| | Adjective | "-er" | "the -est" |
| --- | --- | --- | --- |
| **-szy** after one consonant | *nowy* | *nowszy* | *najnowszy* |
| | *młody, stary* | *młodszy, starszy* | *najmłodszy, najstarszy* |
| | *tani* | *tańszy* | *najtańszy* |
| **k, g** drop or change | *krótki, wysoki* | ***krótszy, wyższy*** | *najkrótszy, najwyższy* |
| | *drogi, długi* | ***droższy, dłuższy*** | *najdroższy, najdłuższy* |
| **-ejszy** after two consonants | *ładny, trudny* | *ładniejszy, trudniejszy* | *najładniejszy, najtrudniejszy* |
| | *ciepły* | ***cieplejszy*** | *najcieplejszy* |
| **irregular** | *dobry* | ***lepszy*** | ***najlepszy*** |
| | *zły* | ***gorszy*** | ***najgorszy*** |
| | *duży* | ***większy*** | ***największy*** |
| | *mały* | ***mniejszy*** | ***najmniejszy*** |
| ***bardziej*** for long words | *interesujący* | *bardziej interesujący* | *najbardziej interesujący* |

Endings agree like any adjective: *starszy brat, starsza siostra, starsze dzieci*; for men **-si**: *moi starsi bracia, lepsi studenci*.

Adverbs ("faster", "better"):

| Adverb | "more …" | "most …" |
| --- | --- | --- |
| *szybko* | *szybciej* | *najszybciej* |
| *tanio, drogo* | *taniej, drożej* | *najtaniej, najdrożej* |
| *często* | *częściej* | *najczęściej* |
| *dobrze* | ***lepiej*** | ***najlepiej*** |
| *źle* | ***gorzej*** | ***najgorzej*** |
| *dużo* | ***więcej*** | ***najwięcej*** |
| *mało* | ***mniej*** | ***najmniej*** |

## When to use it

1. **Comparing two people or things with *niż* (+ the nominative for subjects).** *Mój brat jest starszy niż ja.* (My brother is older than me.)
2. **Or with *od* + genitive (common in speech).** *Pociąg jest szybszy od autobusu.* (The train is faster than the bus.)
3. **The most of a group: *naj-*, often with *w* + locative.** *To najstarsze miasto w Polsce.* (It's the oldest town in Poland.)
4. **Long adjectives and participles: *bardziej / najbardziej*.** *Ten film jest bardziej interesujący.* (This film is more interesting.)
5. **Comparing actions: the adverb.** *Ola mówi po polsku lepiej niż ja.* (Ola speaks Polish better than me.)

## Examples

| Polish | English |
| --- | --- |
| Czy jest coś tańszego? | Is there anything cheaper? |
| Moja siostra jest młodsza ode mnie. | My sister is younger than me. |
| To najlepsza pizza w mieście! | It's the best pizza in town! |
| Dziś jest cieplej niż wczoraj. | It's warmer today than yesterday. |
| Pociągiem jest szybciej i taniej. | It's faster and cheaper by train. |
| Ten pokój jest większy, ale droższy. | This room is bigger, but more expensive. |
| Kto biega najszybciej? | Who runs fastest? |

## Good to know

- *ode mnie* has *ode*; otherwise *od*: *od ciebie, od niego*.
- *coś tańszego* (something cheaper): after *coś* the adjective is in the genitive.
- *Czy jest większy rozmiar?* (Is there a bigger size?) is very useful in shops: [[a2-vocabulary-shopping-clothes]].
- *coraz* + comparative = "more and more": *coraz lepiej* (better and better).

## Common mistakes for English speakers

- ✗ *bardziej tani* → ✓ *tańszy* — short adjectives take *-szy*, not *bardziej*.
- ✗ *dobrzejszy* → ✓ *lepszy* — *dobry, zły, duży, mały* are irregular.
- ✗ *najbardziej dobry* → ✓ *najlepszy* — "best" has its own form.
- ✗ *Ona mówi lepsza niż ja.* → ✓ *Ona mówi lepiej niż ja.* — an action takes the adverb *lepiej*.
- ✗ *Jestem starszy niż jego.* → ✓ *Jestem starszy niż on.* — after *niż* use the nominative.

## Practice

Give the "-er" form.

1. tani → ___
2. dobry → ___
3. duży → ___
4. ładny → ___

Complete the sentence.

5. To (dobry) ___ restauracja w mieście. (the best)
6. Pociąg jedzie (szybko) ___ niż autobus. (faster)

Correct the mistake.

7. Ten hotel jest bardziej tani.

Translate into Polish.

8. My brother is older than me.

## Answers

1. tańszy
2. lepszy
3. większy
4. ładniejszy
5. najlepsza
6. szybciej
7. Ten hotel jest tańszy.
8. Mój brat jest starszy niż ja. / Mój brat jest starszy ode mnie. / Brat jest starszy niż ja. / Brat jest starszy ode mnie.
