# Adverbs, frequency and double negation

English makes most adverbs with "-ly": "quick → quickly". Polish adverbs end in **-o** or **-ie**: *szybko* (quickly), *ładnie* (nicely), *dobrze* (well). Frequency words (*zawsze, często, nigdy*) usually go **before** the verb. And Polish negation is different: *nigdy, nic, nikt* always need ***nie*** before the verb too, and several of them can stand together: *Nikt nic nie mówi.* (Nobody says anything.)

## How it works

Adverbs from adjectives:

| Ending | Adjective → adverb |
| --- | --- |
| **-o** | *szybki → szybko*, *wolny → wolno*, *tani → tanio*, *drogi → drogo*, *cichy → cicho*, *późny → późno* |
| **-ie** (consonant softens) | *ładny → ładnie*, *ciekawy → ciekawie*, *dobry → **dobrze*** (*r → rz*) |
| irregular | *zły → **źle*** (badly) |

How often, from always to never:

| Polish | English |
| --- | --- |
| *zawsze* | always |
| *zwykle* | usually |
| *często* | often |
| *czasami, czasem* | sometimes |
| *rzadko* | rarely |
| *nigdy nie* | never |
| *codziennie* | every day |
| *raz w tygodniu, dwa razy w miesiącu* | once a week, twice a month |

Negative words, each with ***nie*** before the verb:

| Polish | English |
| --- | --- |
| *nikt nie* | nobody |
| *nic nie* | nothing, not … anything |
| *nigdy nie* | never |
| *nigdzie nie* | nowhere, not … anywhere |

They change for case like other words: *nikogo* (nobody, object), *nikomu* (to nobody), *z nikim* (with nobody).

## When to use it

1. **An adverb says how you do something.** *Ola gotuje bardzo dobrze.* (Ola cooks very well.)
2. **After *jest*, with no noun, use an adverb.** *Tu jest cicho.* (It's quiet here.) *Jest późno.* (It's late.)
3. **Frequency words go before the verb.** *Zwykle wstaję o siódmej.* (I usually get up at seven.)
4. **Every negative word needs *nie*.** *Nigdy nie piję kawy wieczorem.* (I never drink coffee in the evening.)
5. **Several negative words together.** *Nikt nigdzie nie idzie.* (Nobody is going anywhere.)
6. **Short answers without a verb: no *nie*.** *Kto dzwonił? — Nikt.* (Who called? — Nobody.) *Co robisz? — Nic.* (What are you doing? — Nothing.)

## Examples

| Polish | English |
| --- | --- |
| Mówisz po polsku bardzo dobrze! | You speak Polish very well! |
| W weekendy zwykle śpię długo. | At the weekend I usually sleep in. |
| Czasami chodzimy na basen. | We sometimes go swimming. |
| Paweł nigdy nic nie mówi o pracy. | Paweł never says anything about work. |
| Wczoraj nigdzie nie byłam. | I didn't go anywhere yesterday. |
| Nikt nie wie, gdzie jest klucz. | Nobody knows where the key is. |
| Byłem tam tylko raz. | I've been there only once. |
| Nie lubię kawy. — Ja też nie. | I don't like coffee. — Me neither. |

## Good to know

- After *nie* the object takes the genitive, also with *nigdy*: *Nigdy nie jem mięsa.* ([[a1-cases-genitive-basics]])
- "Me too" is *Ja też*; "me neither" is *Ja też nie*.
- *dobry* (good) describes a noun, *dobrze* (well) describes a verb: *dobra kawa*, but *dobrze gotuje*.
- *Jest dobrze* means "It's fine".

## Common mistakes for English speakers

- ✗ *Nikt przyszedł.* → ✓ *Nikt nie przyszedł.* — *nikt* needs *nie* before the verb.
- ✗ *Nigdy piję kawę.* → ✓ *Nigdy nie piję kawy.* — *nigdy* needs *nie*, and the object goes into the genitive.
- ✗ *Ona gotuje dobra.* → ✓ *Ona gotuje dobrze.* — how someone does something: the adverb.
- ✗ *Nie wiem coś.* → ✓ *Nic nie wiem.* — "not … anything" is *nic nie*.
- ✗ *Nie lubię kawy. — Ja też.* → ✓ *Ja też nie.* — agreeing with a negative needs *nie*.

## Practice

Make an adverb.

1. szybki → ___
2. ładny → ___
3. dobry → ___

Make the sentence negative with the word in brackets.

4. (nikt) ___ nie wie.
5. Paweł (nigdy) ___ pije kawy.
6. Ja (nic) ___ rozumiem.

Correct the mistake.

7. Ona nigdy ma czas.

Translate into Polish.

8. I usually get up at seven.

## Answers

1. szybko
2. ładnie
3. dobrze
4. Nikt
5. nigdy nie
6. nic nie
7. Ona nigdy nie ma czasu.
8. Zwykle wstaję o siódmej. / Wstaję zwykle o siódmej. / Ja zwykle wstaję o siódmej.
