# Aspect: imperfective and perfective pairs

English shows "was doing" and "did / have done" with different tense forms of one verb. Polish uses **two verbs**. The **imperfective** (*niedokonany*) looks at the action as a process or a habit: *Czytałam książkę.* (I was reading a book.) The **perfective** (*dokonany*) shows one finished action with a result: *Przeczytałam książkę.* (I read the book, I finished it.) From now on every verb on these pages comes as a pair, imperfective first: *robić / zrobić*.

## How it works

Three kinds of pairs. Learn each pair as two words; you cannot guess the prefix.

| Kind | Imperfective | Perfective | English |
| --- | --- | --- | --- |
| a prefix is added | *robić* | *zrobić* | do, make |
| | *pisać* | *napisać* | write |
| | *czytać* | *przeczytać* | read |
| | *pić* | *wypić* | drink |
| | *jeść* | *zjeść* | eat |
| | *gotować* | *ugotować* | cook |
| | *płacić* | *zapłacić* | pay |
| | *iść* | *pójść* (**irregular**: *pójdę, poszedł*) | go (on foot) |
| the ending changes | *kupować* | *kupić* | buy |
| | *wstawać* | *wstać* | get up |
| | *wracać* | *wrócić* | come back |
| | *zamykać* | *zamknąć* | close |
| a different verb | *mówić* | ***powiedzieć*** | say, tell |
| | *brać* | ***wziąć*** | take |
| | *oglądać* | ***obejrzeć*** | watch |

The past tense is built the same way for both: *robiłem → zrobiłem*, *kupowała → kupiła*. Some perfectives have a tricky past:

| Perfective | I (man / woman) | he / she | they (with a man) |
| --- | --- | --- | --- |
| *wziąć* | wziąłem / wzięłam | wziął / wzięła | wzięli |
| *zamknąć* | zamknąłem / zamknęłam | zamknął / zamknęła | zamknęli |
| *zjeść* | zjadłem / zjadłam | zjadł / zjadła | zjedli |
| *pójść* | poszedłem / poszłam | poszedł / poszła | poszli |

A perfective verb has **no present tense**. Its present-looking form means the future: *zrobię* = "I will do". See [[a2-verbs-future-tense]].

## When to use it

1. **Imperfective: a process, "was doing".** *Wczoraj wieczorem czytałem.* (Last night I was reading.)
2. **Imperfective: a habit or a repeated action.** *Codziennie kupowałam chleb.* (I bought bread every day.) Signal words: *codziennie, często, zawsze, zwykle, czasem*.
3. **Imperfective: how long.** *Cały dzień gotowałem.* (I cooked all day.) Signal words: *długo, cały dzień*.
4. **Perfective: one finished action with a result.** *Napisałam e-mail.* (I've written the email, it's done.) Signal words: *już, w końcu*.
5. **Perfective: a chain of events, one after another.** *Wstałem, zjadłem śniadanie i poszedłem do pracy.* (I got up, ate breakfast and went to work.)
6. **Both together: the background and the event.** *Kiedy czytałam, zadzwonił telefon.* (While I was reading, the phone rang. *dzwonić / zadzwonić*: call, ring.)

## Examples

| Polish | English |
| --- | --- |
| Co robiłeś wczoraj? — Oglądałem telewizję. | What did you do yesterday? — I watched TV. |
| Ola zrobiła zakupy i wróciła do domu. | Ola did the shopping and came back home. |
| Kupiłam nowy telefon. | I've bought a new phone. |
| Przeczytałeś już tę książkę? — Jeszcze nie, wciąż czytam. | Have you finished the book yet? — Not yet, I'm still reading. |
| Pan Adam zapłacił kartą. | Mr Adam paid by card. |
| Kasia powiedziała, że jest zmęczona. | Kasia said she was tired. |
| Długo czekaliśmy na autobus. | We waited a long time for the bus. |

## Good to know

- *być, mieć, znać, wiedzieć* have no perfective partner.

## Common mistakes for English speakers

- ✗ *Codziennie zrobiłem zakupy.* → ✓ *Codziennie robiłem zakupy.* — a repeated action takes the imperfective.
- ✗ *Teraz zrobię obiad.* (for "I'm making lunch now") → ✓ *Teraz robię obiad.* — perfectives have no present; *zrobię* means "I'll make".
- ✗ *Cały dzień napisałem raport.* → ✓ *Cały dzień pisałem raport.* — "how long" takes the imperfective.
- ✗ *Wczoraj kupowałam nowy telefon.* (for "I bought") → ✓ *Wczoraj kupiłam nowy telefon.* — one finished purchase takes the perfective.
- ✗ *Wziełam parasol.* → ✓ *Wzięłam parasol.* — the woman's form of *wziąć* has *ę*: *wzięłam*.

## Practice

Choose the right verb.

1. Codziennie (piłem / wypiłem) ___ kawę.
2. W końcu (pisałam / napisałam) ___ ten e-mail.
3. Cały wieczór (oglądaliśmy / obejrzeliśmy) ___ telewizję.
4. Kiedy (jadłem / zjadłem) ___ obiad, zadzwonił telefon. (While I was eating lunch, the phone rang.)

Give the perfective partner.

5. mówić → ___

Correct the mistake.

6. Teraz zrobię obiad. (I'm making lunch now.)

Translate into Polish.

7. Ola paid by card.

## Answers

1. piłem
2. napisałam
3. oglądaliśmy
4. jadłem
5. powiedzieć
6. Teraz robię obiad.
7. Ola zapłaciła kartą.
