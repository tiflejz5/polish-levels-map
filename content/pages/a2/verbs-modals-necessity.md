# Necessity, permission and advice

You know *muszę* (I must) and *mogę* (I can) from A1 ([[a1-verbs-modal-verbs-basics]]). This page adds "should" and a group of words English does not have. *Powinienem / powinnam* means "I should" and changes for the speaker's gender. *Trzeba, można, wolno, warto* have **no person at all**: they mean "one has to", "one can", "one may", "it's worth", and they go straight with an infinitive: *Trzeba czekać.* (You have to wait.) Careful: "you mustn't" is *nie wolno*, not *nie musisz*.

## How it works

*powinien* (should), past-like endings:

| Person | man / group with a man | woman / group without men | it |
| --- | --- | --- | --- |
| *ja* | **powinienem** | **powinnam** | |
| *ty* | **powinieneś** | **powinnaś** | |
| *on / ona / ono, pan / pani* | **powinien** | **powinna** | powinno |
| *my* | powinniśmy | powinnyśmy | |
| *wy* | powinniście | powinnyście | |
| *oni / one, państwo* | powinni | powinny | |

The *e* in *powinien* stays only in the men's singular: *powinienem, powinien*, but *powinna, powinni*.

Words with no person + infinitive:

| Word | Meaning | Negative |
| --- | --- | --- |
| *trzeba* | one has to, it's necessary | *nie trzeba* = there's no need |
| *można* | one can, it's allowed | *nie można* = you can't, it isn't allowed |
| *wolno* | one may | *nie wolno* = you mustn't |
| *warto* | it's worth (doing) | *nie warto* = it's not worth it |

Past and future of these: *trzeba było*, *można było*; *trzeba będzie*, *będzie można*.

## When to use it

1. ***musieć*: you have to, there is no choice.** *Muszę jutro wcześnie wstać.* (I have to get up early tomorrow.)
2. ***powinienem / powinnam*: advice, what is right to do.** *Powinnaś odpocząć.* (You should rest, to a woman.)
3. ***trzeba*: a general necessity, no person named.** *Tu trzeba kupić bilet.* (You have to buy a ticket here.)
4. ***można*: something is possible or allowed.** *Czy można tu zapłacić kartą?* (Can you pay by card here?)
5. ***nie wolno*: a ban.** *Tu nie wolno parkować.* (You mustn't park here.)
6. ***warto*: a recommendation.** *Warto zobaczyć Toruń.* (Toruń is worth seeing.)

## Examples

| Polish | English |
| --- | --- |
| Muszę już iść. | I have to go now. |
| Powinieneś więcej spać. | You should sleep more. (to a man) |
| Nie musisz przychodzić, zrobię to sam. | You don't have to come, I'll do it myself. |
| Czy można tu usiąść? | Can I sit here? |
| W muzeum nie wolno robić zdjęć. | You mustn't take photos in the museum. |
| Trzeba było wziąć parasol! | We should have taken an umbrella! |
| Warto kupić bilet wcześniej. | It's worth buying the ticket in advance. |

## Good to know

- *nie musisz* = "you don't have to"; *nie wolno* = "you mustn't". English "must not" is a ban, Polish *nie musisz* is not.
- After *nie wolno, nie można, nie trzeba* the object takes the genitive: *Nie wolno robić zdjęć.*
- *trzeba było* = "had to" or "should have": *Trzeba było długo czekać.* (We had to wait a long time.)
- For a named person use *musieć* instead of *trzeba*: *Muszę czekać.*

## Common mistakes for English speakers

- ✗ *Ja trzeba iść.* → ✓ *Muszę iść.* — *trzeba* has no person; for "I have to" use *muszę*.
- ✗ *Nie musisz tu palić.* (for "You mustn't smoke here") → ✓ *Tu nie wolno palić.* — *nie musisz* means "you don't have to".
- ✗ *Ona powinien odpocząć.* → ✓ *Ona powinna odpocząć.* — *powinien* agrees with the person: *powinna* for a woman.
- ✗ *To jest warte zobaczyć.* → ✓ *Warto to zobaczyć.* — "it's worth doing" is *warto* + infinitive.

## Practice

Choose the right word.

1. Jesteś zmęczony. (Powinieneś / Powinnaś) ___ odpocząć.
2. Tu nie (wolno / musisz) ___ palić. (You mustn't smoke here.)
3. Jutro jest niedziela, nie (musisz / wolno) ___ wstawać wcześnie.
4. Ten film jest świetny, (warto / trzeba) ___ go zobaczyć. (It’s worth seeing.)

Put *powinien* in the right form.

5. Kasia (powinien) ___ więcej czytać.
6. My (powinien, a group with a man) ___ już iść.

Correct the mistake.

7. Ja trzeba kupić bilet.

Translate into Polish.

8. You mustn't park here.

## Answers

1. Powinieneś
2. wolno
3. musisz
4. warto
5. powinna
6. powinniśmy
7. Muszę kupić bilet. / Trzeba kupić bilet.
8. Tu nie wolno parkować. / Nie wolno tu parkować. / Tutaj nie wolno parkować.
