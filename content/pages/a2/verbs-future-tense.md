# Future tense: będę robić vs zrobię

English chooses between "will" and "going to" by plan or decision. Polish chooses by **aspect**, just like in the past ([[a2-verbs-aspect-introduction]]). Imperfective verbs use ***będę* + infinitive**: *Jutro będę pracować.* (Tomorrow I'll be working.) Perfective verbs need no helper word at all: their present-looking forms already mean the future: *Zrobię to jutro.* (I'll do it tomorrow.)

## How it works

*być* in the future (I will be, you will be…):

| Person | Form |
| --- | --- |
| *ja* | będę |
| *ty* | będziesz |
| *on, ona, ono, pan, pani* | będzie |
| *my* | będziemy |
| *wy* | będziecie |
| *oni, one, państwo* | będą |

**Imperfective future: *będę* + infinitive** (or + the *-ł* form; both mean the same):

| Person | with the infinitive | with the *-ł* form |
| --- | --- | --- |
| *ja* | będę robić | będę robił / robiła |
| *ty* | będziesz robić | będziesz robił / robiła |
| *on / ona* | będzie robić | będzie robił / robiła |
| *my* | będziemy robić | będziemy robili / robiły |
| *wy* | będziecie robić | będziecie robili / robiły |
| *oni / one* | będą robić | będą robili / robiły |

**Perfective future: present endings, future meaning.** A perfective with a prefix conjugates like the verb without it (*pisać → napiszę*); the others have forms of their own (in bold):

| Perfective | *ja* | *ty* | *oni* |
| --- | --- | --- | --- |
| *zrobić* (do) | zrobię | zrobisz | zrobią |
| *napisać* (write) | napiszę | napiszesz | napiszą |
| *kupić* (buy) | **kupię** | **kupisz** | **kupią** |
| *pojechać* (go by vehicle) | pojadę | pojedziesz | pojadą |
| *pójść* (go on foot) | **pójdę** | **pójdziesz** | **pójdą** |
| *zjeść* (eat) | zjem | zjesz | **zjedzą** |
| *wziąć* (take) | **wezmę** | **weźmiesz** | **wezmą** |
| *powiedzieć* (say) | **powiem** | **powiesz** | **powiedzą** |

## When to use it

1. **Imperfective: an activity over time, no result in view.** *Jutro cały dzień będę pracować.* (Tomorrow I'll be working all day.)
2. **Imperfective: a future habit.** *Od poniedziałku będę biegać codziennie.* (From Monday I'm going to run every day.)
3. **Perfective: one action that gets done, a promise.** *Zadzwonię jutro.* (I'll call tomorrow.)
4. **Perfective: a chain of events.** *Zjem obiad i pojadę do pracy.* (I'll have lunch and go to work.)
5. **A fixed plan with a time word: the present is fine, as in English.** *Jutro pracuję.* (I'm working tomorrow.)

## Examples

| Polish | English |
| --- | --- |
| Co będziesz robić w weekend? — Będę odpoczywać. | What are you going to do at the weekend? — I'm going to relax. |
| Zrobię to jutro, dobrze? | I'll do it tomorrow, OK? |
| Pani Ewa będzie pracować w nowym biurze. | Mrs Ewa will be working in a new office. |
| Kupisz chleb? — Tak, kupię. | Will you buy some bread? — Yes, I will. |
| W sierpniu pojedziemy do Gdańska. | In August we'll go to Gdańsk. |
| Napiszę e-mail wieczorem. | I'll write the email this evening. |
| Nie będę mógł przyjść. | I won't be able to come. (a man speaking) |

## Good to know

- After *będę* only an **imperfective** infinitive: *będę robić*, never *będę zrobić*.
- With *móc, musieć, chcieć* people usually use the *-ł* form: *będę mógł / mogła*, *będziesz musiał / musiała*.

## Common mistakes for English speakers

- ✗ *Jutro będę zrobić zakupy.* → ✓ *Jutro zrobię zakupy.* — *będę* goes only with an imperfective verb.
- ✗ *Będę kupię bilet.* → ✓ *Kupię bilet.* — the perfective future needs no *będę*.
- ✗ *Będę jestem w domu.* → ✓ *Będę w domu.* — *będę* already means "I will be".
- ✗ *Jutro przeczytam cały dzień.* → ✓ *Jutro będę czytać cały dzień.* — "all day" is about time, not a result: imperfective.
- ✗ *Pojdę do domu.* → ✓ *Pójdę do domu.* — the future of *pójść* keeps *ó*: *pójdę, pójdziesz*.

## Practice

Put the verb in the future.

1. Jutro (ja, pracować) ___ w domu.
2. (ja, zrobić) ___ to wieczorem.
3. W sobotę (my, pojechać) ___ do Torunia.
4. Kasia (kupić) ___ bilet.
5. Jutro (być) ___ ciepło.

Correct the mistake.

6. Jutro będę zrobić obiad.

Translate into Polish.

7. I'll call tomorrow.
8. What are you going to do at the weekend? (to a friend)

## Answers

1. będę pracować / będę pracował / będę pracowała
2. Zrobię
3. pojedziemy
4. kupi
5. będzie
6. Jutro zrobię obiad. / Jutro będę robić obiad.
7. Zadzwonię jutro. / Jutro zadzwonię.
8. Co będziesz robić w weekend? / Co będziesz robił w weekend? / Co będziesz robiła w weekend?
