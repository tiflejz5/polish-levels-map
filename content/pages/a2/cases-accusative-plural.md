# Accusative plural and masculine personal accusative

In English, "I know the students" and "the students know me" use the same word "students". In Polish the object takes the **accusative** ([[a1-cases-accusative]]). In the plural this is easy: for women, animals and things the accusative is **the same as the nominative plural** (*Lubię koty.*). Only **masculine personal** nouns change: *To są nowi studenci. → Znam nowych studentów.*

## How it works

Everything except men: **no change** from the nominative plural.

| Nominative plural | Accusative plural |
| --- | --- |
| *nowe domy* | *Mamy nowe domy.* |
| *małe koty, duże psy* | *Lubię małe koty i duże psy.* |
| *ciekawe książki* | *Czytam ciekawe książki.* |
| *stare zdjęcia* | *Oglądamy stare zdjęcia.* |

Masculine personal: new endings.

| | Ending | Examples |
| --- | --- | --- |
| nouns | **-ów** | *studenci → studentów*, *Polacy → Polaków*, *koledzy → kolegów*, *synowie → synów*, *panowie → panów* |
| | **-y / -i** after soft consonants | *lekarze → lekarzy*, *nauczyciele → nauczycieli* |
| | irregular | ***bracia → braci***, ***ludzie → ludzi*** |
| adjectives | **-ych** (**-ich** after *k, g*) | *nowych, dobrych, miłych, polskich, drogich* |
| *ten, mój…* | | ***tych***, *moich, twoich, naszych, waszych* |

*rodzice* (parents) is masculine personal: *Odwiedzam rodziców.*

## When to use it

1. **Plural objects of women, animals, things: as the nominative.** *Kupuję jabłka i pomidory.* (I'm buying apples and tomatoes.)
2. **Plural objects of men: -ów / -ych.** *Znasz tych panów?* (Do you know these gentlemen?)
3. **Mixed groups count as men.** *Ania i Paweł to studenci. Znam tych studentów.* (Ania and Paweł are students. I know these students.)
4. **Animals in the plural are like things.** Singular *Mam psa*, but plural *Mam dwa psy*, *Lubię psy*.
5. **Not after *nie*.** A negated object takes the genitive: [[a2-cases-genitive-plural-quantities]].

## Examples

| Polish | English |
| --- | --- |
| Lubię koty, ale wolę psy. | I like cats, but I prefer dogs. |
| W weekend odwiedzam rodziców. | At the weekend I visit my parents. |
| Mamy bardzo miłych sąsiadów. | We have very nice neighbours. |
| Ola zna wszystkie piosenki. | Ola knows all the songs. |
| Czy pan zna moich kolegów? | Do you know my colleagues? |
| Kupiłam nowe okulary. | I've bought new glasses. |
| W teatrze widzieliśmy znanych aktorów. | At the theatre we saw famous actors. |
| Pani Ewa uczy małe dzieci. | Mrs Ewa teaches small children. |

## Good to know

- *dzieci* is not masculine personal: *Mam małe dzieci.*
- The masculine personal accusative is the same form as the genitive plural: *tych studentów*, *moich braci*. That is why you see it again in the next topic.

## Common mistakes for English speakers

- ✗ *Znam te studenty.* → ✓ *Znam tych studentów.* — men take *tych* and *-ów*.
- ✗ *Odwiedzam moje rodzice.* → ✓ *Odwiedzam moich rodziców.* — *rodzice* is masculine personal.
- ✗ *Lubię psów.* → ✓ *Lubię psy.* — the animal *-a* of the singular (*psa*) does not carry over to the plural.
- ✗ *Mam dobre koledzy.* → ✓ *Mam dobrych kolegów.* — the object needs the accusative, not the nominative *koledzy*.

Put the words in brackets into the accusative plural.

1. Lubię (koty) ___.
2. Czytam (polskie książki) ___.
3. Znam (ci studenci) ___.
4. Mamy (mili sąsiedzi) ___.

## Answers

1. koty
2. polskie książki
3. tych studentów
4. miłych sąsiadów
5. jabłka
6. rodziców
7. Znasz moich kolegów?
