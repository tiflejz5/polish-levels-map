# Nominative plural, including masculine personal forms

English adds "-s" to almost everything. Polish has a few plural endings, and it splits the plural into two groups. **Masculine personal** nouns (men, and groups with at least one man) have special forms: *studenci, Polacy, dobrzy lekarze*. **Everything else** (women, animals, things) uses simpler ones: *koty, książki, okna, nowe domy*. It is the same split as *byli / były* in the past tense ([[a2-verbs-past-tense]]).

## How it works

Everything except men:

| Gender | Ending | Examples |
| --- | --- | --- |
| masculine, feminine | **-y** | *kot → koty*, *dom → domy*, *kawa → kawy* |
| | **-i** after *k, g* | *bank → banki*, *książka → książki*, *noga → nogi* |
| | **-e** after soft consonants and *c, cz, sz, rz, ż, l, j* | *pokój → pokoje*, *klucz → klucze*, *ulica → ulice*, *kuchnia → kuchnie* |
| neuter | **-a** | *okno → okna*, *mieszkanie → mieszkania*, *muzeum → muzea* |

Adjectives, *ten* and *mój* for all of these: **-e**: *nowe domy, te książki, moje okna, duże psy*.

Masculine personal: the last consonant often changes.

| Change | Nouns | Adjectives |
| --- | --- | --- |
| **-i**, *t → ci*, *d → dzi*, *n → ni* | *student → studenci*, *sąsiad → sąsiedzi* (also *a → e*) | *nowy → nowi*, *młody → młodzi*, *zmęczony → zmęczeni* |
| **-y**, *k → c*, *g → dz*, *r → rz* | *Polak → Polacy*, *kolega → koledzy*, *aktor → aktorzy* | *wysoki → wysocy*, *drogi → drodzy*, *dobry → dobrzy* |
| **-e** after soft consonants, *cz, sz, rz, l, j* | *lekarz → lekarze*, *nauczyciel → nauczyciele* | — |
| **-owie** (family, titles) | *pan → panowie*, *syn → synowie* | — |
| *ł → l* | — | *mały → mali*, *miły → mili* |

Irregular: ***brat → bracia***, ***człowiek → ludzie*** (men: *moi bracia, ci ludzie*); ***dziecko → dzieci***, ***rok → lata*** (others: *te dzieci, te lata*).

Pronouns: *ci, moi, twoi, nasi* (men) — *te, moje, twoje, nasze* (others).

## When to use it

1. **The subject in the plural.** *Koty śpią.* (The cats are sleeping.)
2. **After *to są*.** *To są moje książki.* (These are my books.)
3. **An adjective after *są*.** *Ci panowie są bardzo mili.* (These gentlemen are very nice.)
4. **A group with at least one man: masculine personal.** *Ania i Tomek są zmęczeni.* (Ania and Tomek are tired.)
5. **Animals are not persons.** *Psy są głodne.* (The dogs are hungry.) Here *-e*, not *-i*.

## Examples

| Polish | English |
| --- | --- |
| To są moi rodzice. | These are my parents. |
| Nasi sąsiedzi są bardzo mili. | Our neighbours are very nice. |
| Te buty są nowe. | These shoes are new. |
| Gdzie są klucze? | Where are the keys? |
| Studenci mają dziś wolne. | The students have the day off today. |
| W centrum są dobre restauracje. | There are good restaurants in the centre. |
| Polacy lubią zupy. | Poles like soups. |
| Dzieci są w ogrodzie. | The children are in the garden. |

## Good to know

- *dzieci* and groups of women take the "others" forms: *Dzieci są małe.* *Siostry są wysokie.*
- *drzwi, okulary, pieniądze* are plural only: *Drzwi są otwarte.* (The door is open.)
- *Państwo* (formal "you") takes masculine personal forms: *Czy państwo są gotowi?* (Are you ready?)

## Common mistakes for English speakers

- ✗ *dobre studenty* → ✓ *dobrzy studenci* — men take the masculine personal forms, with the consonant change.
- ✗ *Polaki* → ✓ *Polacy* — *k → c* in the masculine personal plural.
- ✗ *książky* → ✓ *książki* — after *k* and *g* write *-i*, never *-y*.
- ✗ *moje bracia* → ✓ *moi bracia* — "my" for men is *moi*.
- ✗ *Te panowie są mili.* → ✓ *Ci panowie są mili.* — "these" for men is *ci*.

## Practice

Put the words in the plural.

1. kot → ___
2. książka → ___
3. okno → ___
4. nowy student → ___
5. dobry lekarz → ___
6. Polak → ___

Correct the mistake.

7. Moje bracia są wysocy.

Translate into Polish.

8. Our neighbours are very nice.

## Answers

1. koty
2. książki
3. okna
4. nowi studenci
5. dobrzy lekarze
6. Polacy
7. Moi bracia są wysocy.
8. Nasi sąsiedzi są bardzo mili.
