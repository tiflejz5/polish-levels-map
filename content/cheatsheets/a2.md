# A2 cheat sheet

## Forms

| Form | Singular | Plural |
| --- | --- | --- |
| nominative | *nowy student, nowa kawa* | *nowi studenci* · *nowe domy* |
| accusative | *Znam nowego studenta.* | *Znam tych studentów.* · *Lubię koty.* |
| genitive: *nie ma*, *dużo*, 5+ | *Nie ma biletu.* | *Nie ma biletów.* · *kilka minut* |
| dative: to whom | *Tomkowi, bratu, mamie* | *rodzicom, dzieciom* |
| instrumental: by, with | *autobusem, z mamą* | *z kolegami, z dziećmi* |
| locative: *o, po, przy, w* | *o filmie, po pracy, w maju* | *w sklepach* |
| past: *on / ona* · *oni / one* | *był, szedł* · *była, szła* | *byli, szli* · *były, szły* |
| numbers | 1 *kot* · 2–4 *dwa koty, dwie kawy* | 5+ *pięć kotów, dwanaście lat* |

## Grammar

- **Aspect:** imperfective = process or habit, perfective = one result: *robić / zrobić, kupować / kupić, mówić / powiedzieć*.
- **Future:** *będę robić* (activity) · *zrobię, kupię, pójdę* (one result). Never *będę zrobić*.
- **Motion:** *idę, jadę* = one trip, now or planned · *chodzę, jeżdżę* = habit · *pójść, pojechać* = one finished trip.
- **Pronouns:** *mi, cię, go, mu* and ***się*** never first; after a preposition *z nim, dla niej, ze mną*.
- **Comparing:** *-szy / -ejszy*, *naj-*, *niż*; *bardziej* + long words; *lepszy*; *lepiej*.
- **Negation:** *nikt, nic, nigdy* + *nie*: *Nikt nic nie wie.*
- **Must, should:** *muszę, powinienem / powinnam*; *trzeba, można, warto* + infinitive; *nie wolno* = mustn't, *nie musisz* = don't have to.
- **Commands:** *zrób, weź, idź, chodźmy!* · "don't": *Nie rób tego!* · stranger: *Proszę usiąść.*

## Signal words

| After … | use … | Example |
| --- | --- | --- |
| *codziennie, często* | imperfective | *Często chodzę do kina.* |
| *już, w końcu* | perfective | *W końcu to zrobiłam.* |
| *cały dzień, długo* | imperfective | *Długo czekałem.* |
| *teraz* + one trip | *iść, jechać* | *Teraz idę do domu.* |
| *dużo, kilka*, 5+ | genitive plural | *dużo ludzi* |
| *pomagać, dziękować* | dative | *Pomagam bratu.* |
| *z* (with) | instrumental | *z kolegami* |
| *o* (about), *po* (after) | locative | *o pracy* |
| *niż* (two subjects) | nominative | *starszy niż ja* |
| *nikt, nic, nigdy* | *nie* + verb | *Nikt nie przyszedł.* |

## Watch out

- ✗ *Jutro będę zrobić zakupy.* → ✓ *Jutro zrobię zakupy.*
- ✗ *Często idę do kina.* → ✓ *Często chodzę do kina.*
- ✗ *dobre studenty* → ✓ *dobrzy studenci*
- ✗ *pięć koty*, *dwa kobiety* → ✓ *pięć kotów*, *dwie kobiety*
- ✗ *Pomagam brata.* → ✓ *Pomagam bratu.*
