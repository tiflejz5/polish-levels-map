# A1 cheat sheet

## Forms

| Form | Masculine | Feminine | Neuter |
| --- | --- | --- | --- |
| nominative: subject, *to jest* | *nowy dom* | *nowa kawa* | *nowe okno* |
| instrumental: job after *być*; *z* = with | *Jestem lekarzem.* | *Jest lekarką.* | *z mlekiem* |
| accusative: object | *Mam brata.* · *Mam dom.* | *Piję kawę.* | *Piję piwo.* |
| genitive: after *nie*, *do, z, bez, dla* | *Nie mam czasu.* | *Nie ma kawy.* | *bez mleka* |
| locative: *w, na* (where?) | *w Krakowie* | *w szkole* | *w kinie* |
| "my", "this" | *mój*, *ten* | *moja*, *ta* | *moje*, *to* |
| past: *ja* / *on, ona, ono* | *byłem* / *był* | *byłam* / *była* | *było* |

## Grammar

- **Present:** *czytam, czytasz* · *mówię, mówisz* · *piszę, piszesz* · *-ować → pracuję*. Learn the *ja* and *ty* forms. [[a1-verbs-present-conjugations]]
- ***być*:** *jestem, jesteś, jest, jesteśmy, jesteście, są*. One thing: *to jest*; more: *to są*.
- **Irregular:** *mam, jem, wiem* · *idę, idziesz* · *jadę, jedziesz* · *chcę* · *mogę, możesz*.
- **Formal you:** *pan / pani* + the "he / she" form: *Jak się pani ma?* Never *wy* for one person.
- **Questions:** *czy* + statement, or a question word first. **No:** *nie* before the verb; *nikt / nic / nigdy* + *nie*.
- **Verb + infinitive:** *lubię, chcę, mogę, muszę, umiem* + *czytać, mówić, pływać*.
- **Going:** *iść* on foot, *jechać* by vehicle or to another town. *w sklepie → do sklepu*, *na poczcie → na pocztę*.
- **Nationality:** noun with a capital (*Jestem Polką*), adjective small (*polska kawa*); days and months small too.

## Signal words

| After … | use … | Example |
| --- | --- | --- |
| *to jest* | nominative | *To jest brat.* |
| *jest* + a job | instrumental | *Jest kelnerem.* |
| *mam, lubię, poproszę* | accusative | *Poproszę wodę.* |
| *nie* + object, *nie ma* | genitive | *Nie ma soku.* |
| *do, z* (from), *bez, dla* | genitive | *z Polski* |
| *z* (with) | instrumental | *herbata z cytryną* |
| *w, na* (where?) | locative | *na poczcie* |
| *chcę, mogę, muszę* | infinitive | *Muszę iść.* |
| *wczoraj* | past | *Wczoraj tu byłam.* |
| *o* + an hour | *-ej* | *o siódmej* |

## Watch out

- ✗ *Jestem trzydzieści lat.* → ✓ *Mam trzydzieści lat.*
- ✗ *Jestem student.* → ✓ *Jestem studentem.*
- ✗ *Nie mam czas.* → ✓ *Nie mam czasu.*
- ✗ *Idę do Gdańska pociągiem.* → ✓ *Jadę do Gdańska pociągiem.*
- ✗ *Jestem w poczcie.* → ✓ *Jestem na poczcie.*
